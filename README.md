# Mr. Glass Chicago — Website

Modern, blue-branded, animated, customer-centric website for **Mr. Glass Chicago** — Chicagoland's mobile auto glass company.

## Services Covered
- Windshield Chip Repair
- Auto Glass Replacement (windshields, door glass, rear glass)
- Window Tinting (5% / 15% / 20% / 35% / 50%)
- Mobile Auto Glass Service (we come to you)
- Auto Scratch & Dent Repair

## Pages
| File | Purpose |
|---|---|
| `index.html` | Homepage — hero, services, before/after slider, stats, reviews, CTAs |
| `services.html` | Services overview + process |
| `windshield-chip-repair.html` | Chip repair + FAQ (FAQ schema) |
| `auto-glass-replacement.html` | Replacement services |
| `window-tinting.html` | Tinting + shade selector |
| `mobile-auto-glass-service.html` | Mobile service + steps |
| `scratch-dent-repair.html` | Scratch & dent repair |
| `gallery.html` | Before/after slider + lightbox gallery |
| `about.html` | Company story, values, stats |
| `contact.html` | Quote form, hours, map, socials |

## SEO Included
- Unique title + meta description + canonical per page
- Open Graph + Twitter Card tags
- JSON-LD: `AutoRepair` LocalBusiness (homepage), `FAQPage` (chip repair)
- `sitemap.xml` + `robots.txt`
- Semantic HTML5, descriptive alt text, lazy-loaded gallery images

## Run on Replit
The `.replit` file is included — just import this folder and hit **Run** (serves on port 3000 via `python3 -m http.server`). No build step required; it's a pure static site.

## Run locally
```bash
python3 -m http.server 3000
# open http://localhost:3000
```
